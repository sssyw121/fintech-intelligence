# 텔레그램 HTML 메시지 템플릿

> 이 파일은 `news-reporter` 에이전트가 참조하는 텔레그램 메시지 디자인 가이드입니다.
> 텔레그램 Bot API는 `parse_mode: "HTML"` 에서 `<b>`, `<i>`, `<a>`, `<code>`, `<pre>` 태그를 지원합니다.

---

## 전체 메시지 구조

```
[헤더] 주간 핀테크 인텔리전스
[섹션1] 이번 주 헤드라인
[섹션2] Top 3 이슈
[섹션3] 기회 & 리스크 요약표
[푸터] 한줄 코멘트 + 출처 안내
```

---

## 변수 매핑표

| 변수 | 소스 JSON 경로 |
|------|---------------|
| `period_start` | `period.start` |
| `period_end` | `period.end` |
| `weekly_summary` | `weekly_summary` |
| `issue1_title` | `top_issues[0].title` |
| `issue1_description` | `top_issues[0].description` |
| `issue1_opportunity` | `top_issues[0].opportunity` |
| `issue1_risk` | `top_issues[0].risk` |

## 디자인 원칙

1. **톤앤매너**: 핀테크 시장을 매주 관찰하는 시니어 PM의 브리핑 어조
   - 과장 없이 팩트 중심
   - 액션으로 이어질 수 있는 인사이트 제시
   - 전문 용어는 쓰되 불필요한 수식어 배제

2. **이모지 사용 규칙**
   - 섹션 구분자: `━━━` 또는 `─────`
   - 기회: `💡`, 리스크: `⚠️`, 이슈: `🔥`, 뉴스: `🗞`, 코멘트: `📌`
   - 과도한 이모지 사용 금지 (섹션당 1개)

3. **길이 기준**
   - 전체 메시지: 2000~3500자 권장 (4096자 한도 내)
   - 각 이슈 설명: 2-3문장 (100자 내외)
   - 기회/리스크: 1문장씩

4. **링크 처리**
   - 관련 기사 링크가 있으면 이슈 제목에 인라인 링크 추가:
     `<a href="{{ article_url }}">{{ issue_title }}</a>`
